# Rubric — script (`03-script/script.json`, `script.md`)

| criterion | 1 | 3 | 5 |
|---|---|---|---|
| `hook` | Throat-clearing intro | Clear question in 30 s | Irresistible question + stakes in ≤20 s, visual from the first second |
| `structure` | List of facts | Logical order | Misconception → journey of reveals → twist → resolution; every beat earns the next (open loops closed) |
| `clarity` | Jargon, leaps | Understandable | A smart 15-year-old could re-explain it; each new idea gets one concrete anchor |
| `accuracy` | Errors / distortions | Accurate | Accurate *and* honest about simplifications; every fact beat cites verified claims |
| `voice` | Textbook or hype | Pleasant | Unmistakably the channel: warm, precise, curious; written for the ear |
| `visualizability` | Talking about, not showing | Visual intents present | Every beat has a specific, drawable visual idea; the script exploits animation |
| `pacing` | Monotone density | Varied | Rhythm of tension/release; no beat >~35 s without a new visual idea; payoff lands with room to breathe |
| `ending` | Abrupt / summary | Resolves | Lands the model, then opens a new question worth subscribing for |

Auto-fail: any `script lint` error; a fact beat citing a disputed/rejected claim; the hook's question
is not answered; banned words ("mind-blowing", "insane", "you won't believe").
