# Research notes (2026-10-13)

Why the pipeline is built the way it is. Sources are linked; claims from vendor blogs are marked.

## 1. What the reference demos actually are
All the "made by Claude" demos the brief pointed at are **code-rendered animation**, not video-model
output:

| demo | how it was made |
|---|---|
| [devteamdrew — water-cycle infographic](https://x.com/devteamdrew/status/2099971294204739857) | Claude Opus 5 on a `/goal`, ~4 h from zero to a 4:34 1080p MP4; everything generated by Claude |
| [devteamdrew — "Made with Opus 5.5"](https://x.com/devteamdrew/status/2102436464323661880) | "no framework… made in code with Claude", Claude Code CLI, a personal skill, a previous video as style reference, 3–4 iterations on the soundtrack |

Common pattern: Claude writes deterministic visuals as code → headless browser steps frames → ffmpeg →
long autonomous loops of render, look, fix. Known weak spots reported: audio (SFX "robotic", music took
several tries), layout overlap, and self-review that isn't trustworthy without a rubric. Research
systems agree: **Code2Video** (planner/coder/critic with visual anchors, Manim) and
**TheoremExplainAgent** (5-min Manim videos; layout issues remain) — the critic loop is the lever.

## 2. What "quality" means at the reference channels
- **Kurzgesagt**: research from books/papers/experts; 2–3 internal fact-checkers + 1–3 external
  experts per script; ~100 h of sourcing per video and ≥1,200 h total; public sources doc per video.
  Writing is the bottleneck. They report AI deep-research outlines with only ~80 % of facts traceable.
- **Veritasium**: 30+ staff; format grounded in Derek Muller's PhD on confronting misconceptions
  before resolving them.
- **Fern**: armchair documentaries; moody 3D; ~5 M subscribers. Its video *"The Death of Educational
  Content on YouTube"* (Sept 2026) investigates AI copycat channels (e.g. **Blackfiles-HD**: ~400 K
  subs, 100+ long faceless crime docs, ~4 uploads/week, likely AI-assisted) that mine successful videos
  and out-post the originals.

→ Encoded as: primary-source claims with verbatim quotes, an independent fact-checker, public sources
page, misconception→resolution script structure, consistent visual identity, custom score + SFX.

## 3. The 2026 tool landscape (vendor-reported; verify prices before budgeting)
- **Generative video**: Wan 3.0, Seedance 2.5, Veo 3.1, Kling 3.0, MiniMax H3, Grok Imagine 1.5,
  Runway Gen-4.5, LTX-2.5; ~$0.05–0.40 per second. Sora's app and API were shut down in 2026. Great
  for atmosphere, unreliable for factual diagrams/consistency → **capped, off by default**.
- **Code animation**: HyperFrames (HeyGen, Apache-2.0, HTML+GSAP, built for agents) — chosen;
  Remotion (React; company licence above 3 people); Motion Canvas; Manim (maths).
- **TTS**: ElevenLabs v3 (expressive tags, word timestamps) — chosen; Gemini Flash TTS (cheaper).
  **Music**: ElevenLabs Music is the only option with a documented API and commercial terms.

## 4. YouTube policy constraints
- July 2025: YPP "repetitious" → **"inauthentic content"**: template-made, low-variation,
  mass-produced content is demonetised, judged channel-wide. July 2026 clarification adds generic
  templated videos, manipulative distressing content, and AI likenesses of real people on
  health/legal/finance.
- Altered/synthetic content disclosure for realistic generated people/places/events
  (`status.containsSyntheticMedia` in the Data API). Stylised animation normally doesn't need it.
- Even human channels get hit by automated AI-slop detection (a Kurzgesagt video was throttled in
  2026) → keep the human gates, depth, and visible sourcing.

## 5. Kortix (the runtime)
Agents/skills/memory/triggers are files in git with a `kortix.yaml` manifest (v2). Sessions run in
sandboxes (custom Dockerfile templates, documented up to 32 vCPU/128 GB — this project's sandbox
provider caps a sandbox at 6 vCPU; **no GPU**; a running turn keeps the
sandbox ~4 h). Work reaches `main` via change requests. Human decisions go through the review inbox
(`kortix review submit`). Connectors cap calls at 60 s / 25 MiB, so media APIs are called directly
from the sandbox with secrets.
