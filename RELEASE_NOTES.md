Review, Spaces, live doc editing, and watcher Apps

### New
- Review: agent questions and permission asks no longer block a session. After a short live wait they park in the new Review page, and the answer reaches the session as a new message. (#11797, #11803, #11806)
- Spaces: Slack-style spaces where every message is a thread, with a router that hands work to agents and agents that post into spaces (flags `Spaces-Router`, `Spaces-ChatInput`). (#11712, #11783, #11804, #11838)
- Live co-editing of Artifact docs: people and agents type together, with presence, carets and pointers. Artifact cards show open comment threads. (#11747, #11727, #11730, #11723, #11749)
- Watcher Apps: `kortix apps launch --template watcher` runs a 24/7 watcher in one function. Every App event is visible in an event log, `kortix apps events emit --wait` proves the wiring, and app triggers can expect an event within a time window. (#11818, #11814, #11815, #11817, #11823, #11825)
- Goals: create, pause, resume, restart and answer goals from the Goals page or the home composer, with role-based brief templates. (#11758, #11812, #11828, #11785)
- ChatGPT and Claude logins show the signed-in email, plan, and 5-hour and weekly usage, warn before a limit runs out, and a session moves to the connected account with the most headroom. (#11751, #11756, #11768, #11816, #11820, #11832)
- Voice: a Kortix agent joins a Google Meet with its voice, joins any web call, and speaks into and transcribes audio files. (#11677, #11742, #11829)
- Connect X and YouTube in one click; agents upload videos of any size. (#11781, #11738, #11770)
- Agents can switch models and re-steer a running session. (#11675)
- TUI: `/providers` and `/connectors` connect like the web, and artifacts show in the tray. (#11692, #11698, #11691)
- Capture shows each computer's version, update failures and device details. (#11760)
- Mobile: native interactive Liquid Glass on Expo SDK 58, app version 1.6.0. (#11736)
- Solid colour project icons with Kortix marks and custom colours. (#11846)

### Improved
- Sub-agents, agent messages and workflows show as agent rows. An agent opens in the side panel beside the chat. (#11581, #11753, #11735, #11774, #11776)
- Request logs open the exact session message, with server-side filters. (#11696)
- Routing rules read as one table with a floating save bar. (#11827)
- Send and Customize no longer wait on the slow project detail. (#11754)
- Agents start connections and secret links in the chat instead of sending people to settings. (#11763)
- Up and Down in an empty session composer recall earlier prompts. (#11732)
- Self-hosting: operator addresses cannot be claimed by sign-up, and public instances without email start invite-only. (#11764)
- Closed accounts are erased before day 90, with an evidence row for each decision. (#10797)
- Voice calls are faster and more accurate: cheaper lookups, correct greetings, hints for transcribed files and fewer misheard words. (#11667, #11759, #11766, #11773, #11779, #11790, #11795, #11798, #11799, #11801, #11802, #11809, #11810, #11831, #11836, #11839, #11845)
- Sidebar and session rows are cleaner: one leading mark, type icons, folder-style groups, readable queued messages. (#11726, #11729, #11734, #11767, #11775, #11786, #11789, #11731, #11813)
- The SDK drops its OpenCode-era surface. Kortix CLI versions below 0.14.13 must update. (#11821, #11748, #11777)
- API and SDK fields drop their OpenCode names: read `runtime_session_id`, `runtime_sessions`, `harness_version` and `model`; the `opencode_*` aliases are gone. (#11848)
- Session restore is always on, and an agent on a stateless sandbox is told so. (#11849)
- Error reports name the real API release. (#11854)

### Fixed
- Claude Code turns survive memory pressure, and image-heavy turns stop copying every screenshot on every step. (#11761, #11778)
- A Claude session falls back to the project's fallback model at its plan limit, and an exhausted Claude account shows as a usage limit. (#11822, #11757)
- An always-on App that crashed starts again. Test events no longer count as the App alive. (#11819, #11830, #11833)
- OpenCode-era conversations that never reached the session log are recovered, and the recovery gives up quickly on a stopped box. (#11788, #11834, #11840)
- Shared Drive files stop flipping owners between boxes. (#11807)
- The desktop shows a loader until it answers, never a 404. (#11805)
- Expanded tool trees stay open when a session completes, and "Worked for" never hides a card. (#11673, #11728)
- At most one confirmation or password-reset email per address per minute. (#11792, #11811)
- Security: signed trigger webhooks reject replays, headless auth redirects are allow-listed, voice guests write nothing, and every fixable critical, high, ReDoS and file-race alert is closed. (#11793, #11693, #11771, #11782, #11791, #11794, #11835, #11842, #11847, #11704)
- Git mirror retries on process exhaustion, so secret prompts stop being refused in bursts. (#11701)
- The gateway never plans an image model the project disabled, and explains Claude session-only models. (#11713, #11705)
- Delete-account dialogs state the 14-day grace period and that billing records are kept. (#11678, #11683)
- The TUI keeps your scroll position while a reply streams, and `/link` copies only the session link. (#11682, #11681)
- API validation errors (400) use zod 4 issue codes, for example `invalid_format` instead of `invalid_string`. (#11842)
