# Security policy

## Report a vulnerability

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/kortix-ai/suna/security/advisories/new).
Sign in to GitHub, then select **Report a vulnerability** in this repository's
**Security** tab. Do not report vulnerabilities in public issues or pull requests.

Include the affected version or commit, reproduction steps using synthetic data,
the expected and actual behavior, and the potential impact. Do not include
credentials, personal information, or customer data. Test only systems you own or
have explicit permission to assess. Stop if testing exposes another user's data.

## Supported versions

Security fixes target the latest code on the default branch and the current
production release. Older releases and self-hosted forks do not receive backported
security fixes. Update to the latest release before checking whether a report
still applies. Reports affecting the hosted service are also welcome.

## Response

We aim to acknowledge reports within **5 business days**. This is a target, not a
guarantee or a resolution deadline. We assess impact, coordinate a fix, and discuss
disclosure timing with the reporter in the private report. Keep vulnerability
details private until we agree on disclosure timing.
