# Generative UI (genui) Implementation Plan — master

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Kortix agent can answer with typed UI blocks (cards, comparisons, charts, maps, tabs) that render natively on web, mobile, and any `@kortix/sdk` host, and that fall back to markdown everywhere else, with no regression when the feature is off.

**Architecture:** The agent writes an ` ```openui ` fenced block inside its normal text part. `@kortix/sdk/genui` (framework-free) owns the catalog, prompt, streaming parse, Kortix validation, structural sharing, and markdown fallback, wrapping `@openuidev/lang-core` behind one adapter. `@kortix/sdk/genui/react` is a headless React renderer: each host passes its own component map, so the same renderer serves `apps/web` (DOM), `apps/mobile` (React Native), and third-party hosts (bundled unbranded defaults). A project flag decides whether the agent is taught the catalog at all.

**Tech Stack:** TypeScript 5.9, `@openuidev/lang-core` 0.3.1 (MIT, exact pin), zod 3.25.76 through `zod/v4`, React 19, Bun test, Streamdown (web markdown), react-native-markdown-display (mobile markdown), recharts (web charts), react-native-svg (mobile charts), mapcn + maplibre-gl 6 (web map), maplibre-gl in react-native-webview (mobile map).

**Spec:** `.agents/skills/genui/references/spec.md` — every executor reads it before its first task.

## Global Constraints

Every task's requirements include this section.

- `@openuidev/lang-core` pinned to exactly `0.3.1`. Only files under `packages/sdk/src/genui/` import `@openuidev/*`.
- zod is imported as `import { z } from 'zod/v4'` in genui code (the monorepo resolves `zod@3.25.76`; lang-core needs v4 types).
- `zod` and `@openuidev/lang-core` are **optional** `peerDependencies` of `@kortix/sdk`. Never `dependencies`. An SDK user who never imports `/genui` installs neither.
- `@kortix/sdk` root (`.`) never imports `./genui`. All three genui subpaths go in `NOT_ROOT_REACHABLE` (`packages/sdk/src/root-canonical.test.ts`).
- Never hand-bump `packages/sdk/package.json` `version`.
- Fence tags: `openui` and `openui-lang` are v1. `openui-vN` is version N. The prompt teaches `openui`.
- `kortix.transcript.v1` does not change. No new part type.
- Component limits are copied verbatim from spec §6 into `packages/sdk/src/genui/catalog.ts`. Root holds at most 12 children; nesting at most 4 containers.
- Every URL from model output passes `safeUrl()` (absolute `http:`/`https:` only, ≤ 2048 chars) before it reaches `href` or `src`.
- No skeletons. A pending heavy node (Table, charts, Map) reserves its final height and shows the platform spinner: web `Loading` from `apps/web/src/components/ui/loading.tsx`, mobile `KortixLoader` from `apps/mobile/components/kortix/kortix-loader.tsx`. A pending text node renders nothing.
- Web visuals: `kortix-brand` tokens only; run `.agents/skills/kortix-brand/scripts/audit.sh` on changed files. Icons: Phosphor only (`@phosphor-icons/react` on web, `@/lib/icons` on mobile). No `lucide-react`.
- Mobile visuals: primitives from `apps/mobile/components/ui/*` by direct path (no barrel), colors from `global.css` / `THEME` / `withAlpha`, no hex outside allowlisted files.
- Telemetry carries component names, counts, outcomes, and timings only. Never content, URLs, or IDs.
- Prompt text is generated by `buildGenuiPrompt()`; nothing else writes genui instructions.
- Tests run on Bun (`bun:test`). SDK tests use `describe`/`test` (not `it`).
- One canonical branch: `genui`, worktree `../suna-genui`. Commits: the execution session asks Jay once before the first commit (standing rule), then commits per task.
- No customer data in code, tests, fixtures, commits, or PR text. All fixture values are placeholders.

## Review Focus

Inputs the spec implies, that no single task's happy-path tests cover, ranked by likelihood. Each line names the task that pins it.

1. **Model writes `openui-lang` or `~~~openui` instead of ```` ```openui ````** → renders the same as v1. Pinned in plan-1 Task 2 (`fence.test.ts`) and plan-4 Task 2 / plan-5 Task 2 (fence routing tests).
2. **A block mid-stream when the turn is aborted or errors** → valid statements render, the unfinished one is dropped with a "Response was cut off." note, no raw source, no spinner left spinning. Pinned in plan-1 Task 5 ("after the stream ends, an unfinished statement is dropped"), Task 6 (cut-off markdown), Task 7 (cut-off render), and plan-4 Task 1 ("partial block after the stream ends renders no source").
3. **The agent shows an `openui` example inside a ```` ```md ```` fence** (teaching, docs) → stays a code sample. Pinned in plan-1 Task 2 ("an openui tag inside another fence stays markdown").
4. **A shared or public session viewed by someone whose client has genui off, or an old mobile build** → markdown fallback or raw fence, never a crash. Pinned in plan-1 Task 7 ("disabled renders the markdown fallback") and plan-5 Task 7 (OTA fallback check).
5. **Same statement referenced twice** (`row = StatRow([a, a])`) → unique React keys, no key warning, both render. Pinned in plan-1 Task 5 (`parse.test.ts` "duplicate references get unique ids").

## Architecture

```
Agent (OpenCode or pi)                                         ┌─ apps/web ───────────────────────────────┐
  system prompt += buildGenuiPrompt()   (flag on only)          │ markdown-code.tsx                        │
  reply text: prose + ```openui … ```                           │   genuiVersionFromClassName → GenuiBlock │
        │                                                        │   components = webGenuiComponents        │
        ▼  message.part.delta (unchanged transport)              └──────────────────────────────────────────┘
@kortix/sdk sync-store (unchanged)                                ┌─ apps/mobile ────────────────────────────┐
        │                                                        │ selectable-markdown.tsx FencedCode       │
        ▼                                                        │   genuiVersionOf → GenuiBlock            │
@kortix/sdk/genui ── splitGenui / genuiVersionOf                 │   components = mobileGenuiComponents     │
                  ── createGenuiParser ─ lang-core streaming     └──────────────────────────────────────────┘
                     └ sanitizeTree (limits, slots, depth, URLs) ┌─ third-party host ───────────────────────┐
                     └ shareNodes (identity across ticks)        │ GenuiBlock + defaultGenuiComponents      │
                  ── genuiToMarkdown (copy, export, CLI, relay)  └──────────────────────────────────────────┘
@kortix/sdk/genui/react ── GenuiBlock (headless, memo per node, error boundary, onSettled)
```

## Interface contracts (produced by plan-1, consumed by plans 2–5)

```ts
// @kortix/sdk/genui
export const GENUI_SCHEMA_VERSION: 1;
export interface GenuiNode { id: string; type: string; props: Record<string, unknown>; partial: boolean }
export type GenuiIssueCode =
  | 'schema' | 'unknown-component' | 'wrong-child' | 'url' | 'depth' | 'version' | 'no-root'
  | 'cut-off'                // the stream ended inside this statement
  | 'unsupported-statement'; // Query / Mutation / $state: ignored before Phase 4
export interface GenuiIssue { code: GenuiIssueCode; component?: string; statementId?: string; message: string }
export interface GenuiParseResult { root: GenuiNode | null; pending: string[]; issues: GenuiIssue[]; streaming: boolean }
export type GenuiSegment =
  | { kind: 'markdown'; text: string }
  | { kind: 'genui'; code: string; version: number; closed: boolean };
export function genuiVersionOf(tag: string): number | null;
export function genuiVersionFromClassName(className: string | undefined): number | null;
export function splitGenui(text: string): GenuiSegment[];
export function safeUrl(raw: unknown): string | null;
export interface GenuiParser { update(code: string, streaming: boolean): GenuiParseResult }
export function createGenuiParser(version?: number): GenuiParser;
export function parseGenui(code: string, version?: number): GenuiParseResult;
export function genuiNodeToMarkdown(node: GenuiNode): string;
export function genuiBlockToMarkdown(code: string, version?: number): string;
export function genuiToMarkdown(text: string): string;
export function genuiA11yText(node: GenuiNode): string | null;
export const GENUI_UNSUPPORTED_NOTE: string; // 'This content needs a newer version of Kortix.'
export const GENUI_CUT_OFF_NOTE: string;    // 'Response was cut off.'
export function buildGenuiPrompt(): string;
export const GENUI_PROMPT_VERSION: string; // 8 hex chars

// @kortix/sdk/genui/react
export interface GenuiComponentProps { node: GenuiNode; props: Record<string, any>; renderChild: (node: GenuiNode) => ReactNode; streaming: boolean }
export type GenuiComponentMap = Readonly<Partial<Record<string, ComponentType<GenuiComponentProps>>>>;
export type GenuiOutcome = 'rendered' | 'fallback' | 'parse_error' | 'render_error' | 'unsupported';
export interface GenuiBlockEvent { outcome: GenuiOutcome; components: string[]; msToFirstPaint: number | null; issueCount: number }
export interface GenuiBlockProps {
  code: string; version?: number; streaming: boolean; components: GenuiComponentMap;
  renderMarkdown: (markdown: string) => ReactNode; renderPending?: (node: GenuiNode) => ReactNode;
  enabled?: boolean; onSettled?: (event: GenuiBlockEvent) => void;
}
export function GenuiBlock(props: GenuiBlockProps): ReactElement | null;
export function useGenuiParse(code: string, version: number, streaming: boolean): GenuiParseResult;
export const defaultGenuiComponents: GenuiComponentMap;
```

Prop shapes per component (positional order = OpenUI argument order) are fixed in `catalog.ts` (plan-1 Task 4). Host components read `props` with these names: `Stack{children,direction}`, `Card{title,body,subtitle,image,href,badges}`, `Stat{label,value,delta,trend,unit}`, `StatRow{stats}`, `Table{columns,rows,caption}`, `Compare{items,specs,winner}` + `CompareItem{name,values,pros,cons}`, `RankedList{items}` + `RankedItem{title,reason,meta,image,href}`, `BarChart{categories,series,source,unit}`, `LineChart{x,series,source,unit}` + `Series{name,values}`, `PieChart{slices,source,unit}` + `Slice{label,value}`, `Map{markers,source,zoom,route}` + `Marker{lat,lng,label,description}`, `Tabs{tabs}` + `Tab{label,children}`, `Accordion{items}` + `AccordionItem{title,children}`, `Badge{label,tone}`, `Callout{tone,body,title}`, `Image{src,alt,caption}`, `Link{label,href}`.

## Delivery and verification (CLAUDE.md rules, applied)

1. **PR 1** (plan-1 + plan-2 + plan-3): flag ships with `platformDefault: () => false` and `catalogHidden: true` until PR 2 lands, so no project can turn it on before web renders blocks.
2. **PR 2** (plan-4): removes `catalogHidden` from the `genui` flag entry.
3. **PR 3** (plan-5): mobile OTA. The flag needs no change.
4. Before each PR: the narrowest tests named in each task, then `pnpm test`, then `pnpm test:verify --rev HEAD --branch genui` exits `0`. Start the worktree stack (`pnpm worktree start genui`, background) and drive the behavior: PR 1 — create a project, turn on `genui`, start a session, assert `/tmp/kortix/genui.md` exists in the sandbox and the reply carries an ```` ```openui ```` block for a comparison prompt and none for "hi"; PR 2 — agent-browser journey with recording; PR 3 — Expo dev build on the iOS simulator is out (standing rule: no simulator), so Jay checks on device; the executor runs `bun test` and attaches the OTA update ID.
5. Self-merge each verified PR to `dev` (`gh pr merge <n> --squash`), then `git merge origin/dev` into `genui` before continuing (squash merges break ancestry; compare content, not ancestry).
6. Deploy dev: `gh workflow run deploy-dev.yml --repo kortix-ai/suna -f surface=changed`; wait; `/health` on api and web must serve the merge SHA. Repeat the PR's user-visible check against `https://dev.kortix.com` / `https://dev-api.kortix.com`.
7. **Rollout** (Phase 3, spec §11): turn the flag on for internal projects; watch `genui_block` in PostHog for 3 days (parse_error ≤ 1%, overuse 10–25% of turns); then 1% → 10% → 50% → 100% of projects by `platformDefault` change PRs, 3 days per step. Kill switch: set `GENUI_ENABLED=false` in the API environment (plan-3 Task 2) and redeploy; verify a new session has no `/tmp/kortix/genui.md`. Release to staging/prod follows the **kortix-release** skill and needs Jay's approval.
8. **Learnings:** any incident during rollout gets a ledger entry (`.agents/skills/learnings/scripts/new-entry.sh`).
9. **Docs and discovery:** `apps/web/content/docs/sdk/genui.mdx` (plan-1 Task 9), settings rows on web and mobile (plan-4 Task 5, plan-5 Task 5), changelog entry at GA.
