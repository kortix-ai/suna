Kortix is an open-source CompanyOS: the cloud-native agent harness for companies. Events start your agents, My Kortix routes the work, and agents run in parallel, each on its own cloud computer. Start with the Guide to learn what each part does and how to set it up. Go to Developers to build on Kortix from code or run it on your own servers.
